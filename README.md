# Water Level Indicator

An Arduino UNO based water level indication system developed and simulated using Tinkercad.

## Components

- Arduino UNO
- Breadboard
- 4 LEDs
- 4 × 220Ω resistors
- 4 Push Buttons
- Jumper Wires

## Water Level Indication

- 🔴 Red LED – LOW
- 🟡 Yellow LED – MEDIUM
- 🟢 Green LED – HIGH
- 🔵 Blue LED – FULL

## Simulation

The project was designed and tested using Tinkercad Circuits.
